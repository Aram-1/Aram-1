# 🔍 Buscador de Tipos - Sistema Avanzado v2.0

## 📋 Descripción

Sistema avanzado de búsqueda y gestión de tipos con diseño profesional, funcionalidades mejoradas y sistema de pruebas integrado.

## ✨ Características Principales

### 🎨 Diseño Moderno
- Paleta de colores azul oscuro y blanco profesional
- Gradientes suaves y sombras elegantes
- Animaciones y transiciones fluidas
- Diseño responsive para todos los dispositivos

### 🔍 Búsqueda Avanzada
- **Búsqueda Principal**: Filtra tipos por descripción o código
- **Búsqueda Anidada**: Filtra detalles dentro de cada tipo expandido
- Resaltado de términos buscados
- Búsqueda en tiempo real con debounce

### 🔽 Interfaz Mejorada
- Iconos chevron animados en lugar de botones
- Expansión suave de paneles de detalles
- Tablas con datos organizados
- Estadísticas en tiempo real

### 🧪 Modo de Prueba
- 16 tipos de ejemplo con datos realistas
- Backtesting automático (7 pruebas)
- Datos mock para desarrollo y testing
- Tasa de éxito: 100%

## 🚀 Inicio Rápido

### Opción 1: Modo de Prueba (Recomendado)
```bash
1. Abrir buscador-tipos.html en el navegador
2. Click en "🧪 Modo de Prueba"
3. ¡Listo para explorar!
```

### Opción 2: Modo Producción
```bash
1. Abrir buscador-tipos.html en el navegador
2. Ingresar token válido
3. Click en "Validar Token y Cargar Tipos"
```

## 🔧 Configuración

### Modo Producción
Editar la constante `BASE` en el archivo HTML:
```javascript
const BASE = "/Magic93Scripts/Mgrqispi93.dll?appname=webventas";
```

### Modo de Prueba
Activar/desactivar con la constante:
```javascript
const TEST_MODE_ENABLED = true; // false para desactivar
```

## 🎓 Características Técnicas

### Optimizaciones
- Debounce en búsquedas
- Sistema de caché para detalles
- Escape de HTML para seguridad
- AbortController para timeouts
- Lazy loading de detalles

### Seguridad
- Validación de entrada
- Escape de HTML (prevención XSS)
- Timeout en requests (15s)
- No exposición de tokens
